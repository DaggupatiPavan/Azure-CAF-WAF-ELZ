## Study Rule

When researching Azure architecture:

1. Start with Microsoft Learn.
2. Read the architecture reference.
3. Understand the trade-offs.
4. Reproduce the architecture in a lab.
5. Document it with IaC.
6. Explain it verbally as if answering an interview question.
